# CLAUDE.md - Token Lab

Мозок проєкту для Claude Code. Читай перед кожною задачею.

## Що це
Token Lab - веб-інструмент для дизайнерів. Вводиш бренд-колір (hex) і отримуєш:
1. Тональну шкалу 50…950 для brand і neutral, усі значення в hex.
2. Семантичні токени: bg, surface, text, text-muted, border, accent, accent-hover, on-accent, danger, success. Світла і темна тема.
3. Перевірку контрасту WCAG на живому UI (кнопка, картка, інпут) з бейджами AAA / AA / AA Large / Fail.
4. Експорт: CSS variables, Tailwind (v4 `@theme`), tokens.json (variables: primitives → light / dark, формат DTCG). Кнопки «Копіювати».
5. «Поділитися» - зберегти палітру і отримати коротке посилання `/p/abc123`.

Аудиторія - дизайнери. Вони судять по візуалу, тож UI має бути охайним.

## Стек (не міняти без запиту)
- Чистий HTML + CSS + vanilla JS (ES modules). Без фреймворків, без збірки, без npm-залежностей у рантаймі.
- Хостинг: Cloudflare Pages. Бекенд: Pages Functions у `functions/`. База: Cloudflare D1, binding `DB`.
- Локально: `npx wrangler d1 execute token-lab --local --file=schema.sql` (один раз), потім `npx wrangler pages dev` (бере D1 з `wrangler.toml`, локальна база в `.wrangler/`, нічого не йде в клауд). Прапорець `--d1 DB` НЕ додавати - він створює окрему порожню базу без таблиць.
- Тести математики кольору: `node --test` (вбудований раннер Node, без бібліотек).

## Структура
```
public/
  index.html        # один екран
  styles.css        # стилі застосунку
  app.js            # UI: стан, рендер, події
  color.js          # математика: шкала від hex, контраст WCAG (чисті функції, назовні тільки hex)
  tokens.js         # семантичні токени + експорт CSS / Tailwind / tokens.json
functions/
  api/palettes.js        # POST - зберегти палітру, повертає { id, url }
  api/palettes/[id].js   # GET - віддати палітру
  p/[id].js              # /p/abc123 -> віддає index.html, клієнт підтягує палітру
schema.sql          # таблиця palettes
wrangler.toml       # name, pages_build_output_dir, d1_databases
tests/color.test.js
design/             # скрін з Figma, від якого будуємо
```

## Правила
- Спершу план, потім код. На велике завдання - коротко план пунктами і чекай «ок».
- Мова інтерфейсу - українська. Без довгих тире у текстах, тільки звичайний дефіс "-".
- Дизайн: беремо з `design/` (або Figma через MCP). Шрифти Geist + Geist Mono (Google Fonts). Нейтральний фон, тонкі лінії 1px, сітка, без градієнтів, без емодзі, без "AI-фіолетового".
- Колір застосунку і колір палітри - різні речі. UI інструмента нейтральний, палітра живе тільки у свотчах і прев'ю.
- Усі кольори UI - через CSS-змінні в `:root`. Жодних хардкод-hex у компонентах.
- Адаптив: від 360px. На мобільному одна колонка, без горизонтального скролу.
- Стани: невалідний hex - помилка під полем, а не тиша. Копіювання - тост «Скопійовано». Фокус видно з клавіатури.
- Математика кольору - тільки в `color.js`, чисті функції, покриті тестами. Після змін у ній - `node --test`.
- Після кожного кроку перевір у браузері і скажи, що саме перевірити мені.
- Секрети ніколи в коді. D1 id у `wrangler.toml` не секрет, токени Cloudflare - секрет.
